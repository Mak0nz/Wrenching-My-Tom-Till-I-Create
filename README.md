# Wrenching My Tom Till I Create

---

This datapack makes all blocks from Tom's Simple Storage wrenchable with the Create mod wrench (instantly stashing the blocks into the inventory).

Requires [Tom's Simple Storage](https://modrinth.com/mod/toms-storage) and [Create 6+](https://modrinth.com/mod/create) to be installed.

[Tom's Create Storage resource pack](https://modrinth.com/mod/toms-create-storage) is also recommended, but not required.

*You can't use the rotation functionality of the Create mod wrench on the blocks (yet).*
